# Example catalog

`incus-apply` ships example configurations grouped by use case.

| Example set | Summary |
| --- | --- |
| [Reusable resources](resources/) | Individual resource definitions for quick testing and composition. |
| [WordPress](wordpress/) | End-to-end application deployment as OCI containers, a system container, or a VM. |
| [Nested Incus VM](incus-vm/) | Provision an Incus host inside a VM, including ZFS-backed variants. |
| [Incus OS](incus-os/) | Generate an Incus OS installation ISO and launch the installation. |
| [Windows](windows/) | Download Windows and VirtIO ISOs, then create a Windows 11 VM. |

All example source files live in the repository under `examples/`. Use the documentation pages here for the narrative overview and the source files for the exact manifests.
